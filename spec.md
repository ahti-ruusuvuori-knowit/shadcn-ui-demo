# Tech stack
- Vite
- TypeScript
- React
- Tailwind CSS

# Purpose
A single page sample webpage that serves as a presentation platform for a short 10-15 minute demo about using the shadcn/ui component library and customizing its components

# Structure
- Short explanation of what shadcn/ui is and how it works
- A simple sample dashboard with a different UI components
- 3 example live component implementations

# Audience
Software developers with previous experience in front-end development

# Tone & Appearance
- Simple, modern, informative, lighthearted
- Darkmode (dark background, light foreground)
